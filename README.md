# Vigil

An open-source reliability workspace: watch services, investigate incidents, and turn recovery work into action.

Vigil is being built with FastAPI, React, PostgreSQL, and a reproducible DevOps delivery pipeline. The original [session 21 capstone](https://github.com/Nency-Ravaliya/devops-heros/tree/main/session21-python) is the engineering baseline; this is an original product domain and implementation.

## Delivery status

Project foundation is in progress. Deployment and test results will be documented here only after verification.

## Planned core

- Isolated workspaces with sign-in and a disposable interactive demo.
- Service checks, incident timelines, recovery tasks, and downloadable postmortems.
- A cinematic, accessible React interface with reduced-motion support.
- Python tests, non-root Docker images, PostgreSQL migrations, CI security scans, Helm, and cloud infrastructure.

AWS hosting will use an affordable profile once account credits and access are verified. The full EKS capstone profile will be documented separately because the control plane has an hourly cost.
